Counter Application – React

Project Overview

A simple Counter Application built using React to understand and practise the useState hook and state management.

Features

Increment: Increases the counter value by 1.

Decrement: Decreases the counter value by 1.

Reset: Resets the counter value to 0.

Conditional Rendering: Displays "Minimum limit reached" when the counter reaches zero.

Minimum Limit: Prevents the counter from going below zero.
